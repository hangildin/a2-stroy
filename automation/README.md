## Следующая стадия: код уже сохранён в этом репозитории

Файл: [Code.gs](./Code.gs). Код проверен на синтаксис и на модели Gmail/Google Script (без реальных отправок) в случаях:
- выключенный режим: 0 отправлений;
- адрес владельца в боевой очереди: блокируется;
- адрес с уже отправленным письмом: блокируется;
- имитация успешной отправки: 1 письмо и запись в журнал;
- дневной лимит: блокирует отправку.

**ВАЖНО:** скрипт пока НЕ установлен и НЕ авторизован в Google Apps Script. Самостоятельная отправка с него НЕ запущена. Вызов `awfRunApprovedBatch` по умолчанию ничего клиентам не отправляет.

## Первичная настройка, без платных AI-сервисов

1. Открыть Google Apps Script в аккаунте `hangildin@gmail.com` (можно использовать существующий скрипт этого аккаунта) и добавить содержимое `Code.gs`.
2. В **Project Settings → Script properties** внести приватную очередь клиентов в `AWF_LEADS_JSON`. Пример ниже содержит вымышленные реквизиты и **не годится для реальной рассылки**:

```json
[
  {
    "company": "Пример компании",
    "email": "example@example.com",
    "before": "https://example.com/",
    "after": "https://hangildin.github.io/a2-stroy/demo/example/"
  }
]
```

3. Выполнить `awfStatus` и проверить, что `liveEnabled: false` и что ничего не отправлено. Система не создаёт триггеры.
4. **Только после отдельного разрешения** на рассылку реальным клиентам установить `AWF_LIVE_MODE = ENABLED`. Перед этим подтвердить реальную клиентскую очередь и проверить прежние адреса в Gmail.
5. Триггер по времени подключать **только после проверки имеющихся триггеров** через `awfStatus` и отдельного разрешения. Не запускать Hermes.

### Защита от повторов

- В режиме по умолчанию реальные письма запрещены.
- Прежние отправки проверяются через поиск в папке `SENT` Gmail по каждому адресу, включая письма, отправленные вручную до автоматизации.
- Повторные письма внутри одной очереди блокируются; постоянные записи `AWF_SENT_<hash>` и `AWF_EXCLUDE_<hash>` лежат в Script Properties.
- Отдельный стоп-лист `AWF_STOPLIST_JSON` и принудительное исключение Legoremont.
- Демо должно быть доступно по HTTPS с кодом 200. Без работающего демо письмо не уходит.
- Максимум **1 письмо за запуск**, **5 писем за сутки**, интервал не меньше **60 минут**. Это стартовые ограничения, не согласованный объём коммерческой рассылки.
- В `AWF_LOG_*` хранится журнал событий, функция `awfStatus` показывает события, лимиты и имеющиеся триггеры.

### Важная граница

Ни подключение Gmail к ChatGPT, ни три успешных тестовых письма не выдают Google Apps Script разрешения на самостоятельную отправку. Для автономной рассылки нужен **однократный запуск и авторизация скрипта в аккаунте владельца**. Не вводить пароль Gmail в код или публичный репозиторий. До этого система работает только как проверенный, но не развернутый механизм.
